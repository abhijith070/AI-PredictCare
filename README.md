# 🩺 AI PredictCare – Health Risk Prediction System

AI PredictCare is a machine learning-based health risk prediction system designed to predict potential health risks using patient health parameters. The project uses machine learning models and provides an interactive interface for making predictions.

## 📌 Project Overview

AI PredictCare uses health-related input features to predict the risk of diseases using trained machine learning models.

The project currently focuses on:

* 🩸 Diabetes Risk Prediction
* ❤️ Heart Disease Risk Prediction
* 📊 Exploratory Data Analysis
* 🤖 Machine Learning Model Training
* 📈 Model Performance Evaluation
* 🌐 Interactive Prediction using Streamlit

## 🚀 Features

* User-friendly prediction interface
* Diabetes risk prediction
* Heart disease risk prediction
* Data preprocessing and cleaning

## 📊 Dataset

The project uses datasets containing health-related features for diabetes and heart disease prediction.

### Diabetes Dataset

The diabetes dataset contains features such as:

* Pregnancies
* Glucose
* Blood Pressure
* Skin Thickness
* Insulin
* BMI
* Diabetes Pedigree Function
* Age

### Heart Disease Dataset

The heart disease dataset contains patient-related medical and demographic features used for heart disease risk prediction.

## 🤖 Machine Learning Models

Different machine learning algorithms can be trained and compared in the project, including:

* Logistic Regression
* Random Forest
* Support Vector Machine
* Gradient Boosting

The trained models are saved as `.pkl` files and loaded by the application for prediction.

## 📈 Model Performance

### Diabetes Prediction

The selected Gradient Boosting model achieved approximately:

| Metric    | Score |
| --------- | ----: |
| Accuracy  | 88.3% |
| Precision | 83.3% |
| Recall    | 83.3% |
| F1 Score  | 83.3% |
| ROC-AUC   | 95.7% |

> Performance may vary depending on the train/test split, preprocessing, and model configuration.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/abhijith070/AI-PredictCare.git
```

### 2. Open the project

```bash
cd AI-PredictCare
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

#### Windows PowerShell

```powershell
venv\Scripts\Activate.ps1
```

If PowerShell blocks script execution, you can use:

```powershell
venv\Scripts\activate
```

or activate the environment through the VS Code Python environment selector.

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔄 Model Training

To train the diabetes prediction model:

```bash
python train_model.py
```

To train the heart disease prediction model:

```bash
python train_heart.py
```

## 📊 Exploratory Data Analysis

Run:

```bash
python eda.py
```

This performs exploratory analysis and visualization of the dataset.
